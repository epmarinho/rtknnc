# Submission figure subset

This directory contains only the graphics and generated table fragments used
by `paper/round_trip_knn_nca_sn_vote_models.tex`.

Unused figures and supporting experiment artifacts were moved, with their
relative paths preserved, to `../../paper_figures_archive/` on 2026-09-02.
Running `tools/generate-article-figures.sh` will regenerate the larger article
artifact package under this directory.
