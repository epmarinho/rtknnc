# Archived paper figures and experiment artifacts

This directory contains files moved from `paper/figures/` on 2026-09-02 because
they are not referenced by the current manuscript
`paper/round_trip_knn_nca_sn_vote_models.tex`.

The original paths below `paper/figures/` are preserved relative to this
directory. Nothing was deleted. The current manuscript graphics and its two
generated table fragments remain under `paper/figures/` so that the article
can still be compiled and uploaded to Overleaf without this archive.

The full generated package can also be recreated with:

```bash
conda run -n aniso-gnn bash tools/generate-article-figures.sh
```
